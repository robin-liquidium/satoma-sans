# Satoma Sans provenance

Satoma Sans is a modified version of **Albert Sans**. It is not a from-scratch
or exclusively owned font design. Release 0.302 changes packaging, provenance,
and metadata only; its font outlines and spacing match 0.301.

## Changes

- Eighteen static styles: nine upright weights (100–900) and nine italic
  companions, optically selected from Albert's upright and native italic axes.
  The four established upright weights retain their existing outlines.
- Native italic contours are temporarily deskewed around the x-height midpoint
  to apply shared design edits, then restored to their original 11.25-degree
  angle. The italic is not generated by slanting the upright font.
- One-sided rounding on L, b, d, p, q, k, h, l, and the top of t.
- Rounded ear/spur corners on a, b, d, g, m, n, p, q, r, and u.
- Original shoulder curves retained: no swollen connector geometry is added.
- b/d/h/k/l ascenders aligned to cap height; i/j dots vertically repositioned.
- Thin, Extra Light, and Light dots on i/j/į and the fi ligature match the
  period's dimensions, in upright and italic, without changing their centers.
- A returning y descender and diagonal Q tail, anchored inside the counter
  with a consistent shallow baseline extension. A newly constructed g hook
  returns upward to a horizontal-cut terminal, keeping Albert's bowl geometry.
- Shared x-height/descender proportions and opened counters on a/b/d/p/q/g.
- Tuned L/m/n/h/u widths, round i/j dots, and local wordmark pair corrections.
- Modestly narrower wide letters, especially C/c/e, with subtler changes in
  heavier weights. Slightly tighter letter sidebearings and a separate qu
  correction. Version 0.300 then makes the approved tighter tracking native.
- Pair-specific clearance corrections protect close combinations such as ty.
- Native advances now include the approved -0.025em tracking, including spaces
  and proportional reduction for standard ligatures. Existing upright outlines
  are unchanged; focused pair corrections preserve clearance in all styles.
  Use CSS letter-spacing: 0 for the default.
- Ten unencoded tabular digits in every style, accessible through `tnum`, retain
  each digit's outline and center it in a shared advance. Default digits remain
  proportional. Underline/strike metrics and native italic caret slope retained.
- Correct legacy Regular/Bold/Italic style linking and one typographic family
  prevent the expanded styles from overwriting one another in desktop apps.
- Albert's Latin/extended Latin coverage and OpenType features retained.
  No Cyrillic glyphs are claimed or silently imported from another font.

No TT Commons Pro/Liquidium font data, SVG paths, or kerning is imported.
The shared visual brief is not a claim of TypeType endorsement or a blanket
legal clearance for trademarks or other third-party rights.

## Rebuild

Install `font/requirements.txt`, then run `python font/scripts/generate_satoma.py`.
Only the bundled Albert sources and Satoma's pair correction data are read.
Run `python font/scripts/audit_satoma_family.py` with Pillow, numpy, and uharfbuzz
installed to verify all styles; `--proof` creates visual specimen sheets.
